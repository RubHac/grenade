# Accessibility, language and RTL — Level 3

Read when creating interactive, mobile, multilingual, Hebrew/Arabic or RTL content.

- Set document/container direction and language appropriately when the medium supports it. In mixed LTR/RTL content, isolate numbers, code, paths and foreign-language labels so reading order is stable.
- Use semantic headings, real form labels, usable keyboard focus and navigable controls in HTML.
- Preserve meaningful text equivalents for essential visual data; charts should not be the only source for material facts.
- Check readable contrast, text scaling, tap targets and non-color status cues.
- Test at narrow and wide widths when tools are available. Avoid overflow and clipped critical information.
- Respect reduced-motion preferences and accessibility requirements of the target medium.
- Do not invent a visual purely to satisfy a layout rule; R02 explicitly makes visuals conditional on comprehension benefit.
