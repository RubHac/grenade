# Format selection — Level 3 (R01)

**The user's explicit request determines the delivery format.** The reader's job determines the content architecture and narrative, not the file extension.

| Requested medium | Appropriate realization |
|---|---|
| HTML / interactive webpage | Web/HTML artifact using relevant workflow; apply style kit and interactive checks |
| PDF | PDF deliverable using suitable available creation tools; validate pages, pagination and readability |
| Word/document | Editable document in the requested supported format, with appropriate headings and structure |
| PowerPoint/slides | Presentation file; slide workflow applies, not an HTML slideshow substitute |
| Spreadsheet | Workbook with structured data, formulas and checks as appropriate |
| Plain text / message | Respond directly when it fulfills the request |
| No format specified | Choose based on reuse, editing, interaction and delivery expectations; ask only if materially ambiguous |

Do not silently replace a requested format with HTML. Do not manufacture or claim unavailable export/hosting capabilities. Use the visual design principles only where they apply to the chosen medium.
